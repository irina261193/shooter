# ENGLISH OPS: SECRET BASE

[Открыть игру](https://irina261193.github.io/shooter/)

## Урок на 60 минут — обновление 5 октября 2026
- 0–5: знакомство и игрушки.
- 5–17: Presentation — what/where/who, множественное число, are.
- 17–45: Practice — аудирование, окончания, семья, двигательная пауза, письмо, грамматика.
- 45–60: Production — подготовка команды, самостоятельный рассказ, три вопроса учителю, новая ситуация и финал.

В игре 55 экранов и пошаговые устные микромиссии. После CHECK в аудировании, окончаниях, пропусках и правописании ученик читает ответ вслух; учитель нажимает «Прочитано». В рассказе опоры скрываются после репетиции. Произношение автоматически не оценивается.

Таймер запускается вручную, умеет ставить урок на паузу и сохраняет время. После перезагрузки остаётся на паузе. Время — ориентир, без принудительных переходов. В «План PPP» есть подробный сценарий каждого блока и десять резервных устных миссий на 1–2 минуты. Для быстрого ученика доступны бонусы; для медленного оставляйте больше времени на речь.

Если ранее игра уже пройдена, нажмите **«Новый урок»** и подтвердите сброс. Старые ответы и жетоны специально не удаляются автоматически. Пять наград не дублируются.

## Озвучка
Основная речь — **51 готовый WAV-файл компьютерного синтеза Microsoft Zira Desktop (en-US)**. Файлы размещены вместе с игрой и не зависят от установленных на устройстве английских голосов. Для слова aunt при подготовке использована фонемная разметка /ɑːnt/. Для британских особенностей чтения педагог может дополнительно дать собственный образец.

Это синтетическая озвучка, **не человеческие записи и не оригинальные треки учебника**. Треки 57, 59, 60, 61 по-прежнему нужно подключить отдельно в панели учителя; песня и стихотворение не реконструированы.

Резерв при ошибке загрузки — browser speechSynthesis: ожидание английских голосов, предпочтение en-GB, последовательное чтение предложений, один повтор при зависании и понятное сообщение при ошибке. REPEAT останавливает предыдущую речь. Медленный повтор готовых файлов — 0.75× с сохранением высоты голоса. LISTEN, REPEAT и Стоп работают после действия пользователя. Каналы речи, эффектов и музыки независимы; музыка затихает во время речи.

## Запуск и материалы
Для локального запуска скачайте все файлы вместе с папкой assets и откройте index.html. Прогресс хранится в этом браузере. Учительская панель находится под заданием.

Упражнения взяты с предоставленных фотографий печатных страниц 63, 64, 66, 67, 68. Исходные тексты и номера сохранены; авторские адаптации обозначены. Обе сетки кроссвордов сохранены. Робот — оригинальная иллюстрация ImageGen.
