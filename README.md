# ENGLISH OPS: SECRET BASE

Игра: https://irina261193.github.io/shooter/

Образовательная игра для совместного 60-минутного урока с учителем: 51 задание, пять модулей, Presentation → Practice → Production, кроссворды, устный рассказ, панель учителя и пять уникальных жетонов.

Для локального запуска скачайте все файлы и откройте index.html. Прогресс хранится в браузере. Панель учителя позволяет переходить между заданиями, подтверждать устные ответы, показывать подсказки и регулировать бонусные упражнения.

Учебная речь — browser speechSynthesis с английским голосом. Музыка и эффекты создаются Web Audio API. Оригинальные треки учебника 57, 59, 60, 61 не приложены; их можно подключить в панели учителя. Синтез не заменяет оригинальные песню и стихотворение.

Упражнения перенесены с предоставленных фотографий печатных страниц 63, 64, 66, 67, 68. Источники и авторские адаптации обозначены в панели учителя. Робот — оригинальная иллюстрация ImageGen.

Проверено в Edge: прохождение всех 51 заданий, правильные ответы, оба кроссворда, клавиатура, сохранение после обновления, уникальность жетонов и экраны 1440 / 768 / 390 px.
